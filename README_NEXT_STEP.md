# CedarForma v10: следующий шаг

Добавлено:

1. Telegram-уведомления о новых заявках.
2. Простая защита формы от спама: максимум 5 заявок с одного IP за 10 минут.
3. Запуск одной командой из корня проекта:

```bash
npm run dev
```

## Как включить Telegram-уведомления

1. Создай бота через @BotFather.
2. Получи `TELEGRAM_BOT_TOKEN`.
3. Напиши своему боту любое сообщение.
4. Узнай свой `chat_id` через:

```bash
https://api.telegram.org/bot<ТОКЕН>/getUpdates
```

5. В `server/.env` добавь:

```env
TELEGRAM_BOT_TOKEN=твой_токен
TELEGRAM_CHAT_ID=твой_chat_id
```

6. Перезапусти сервер.

Если переменные не указаны, сайт работает как раньше, просто без уведомлений.
