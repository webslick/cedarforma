# CedarForma production notes

## Что добавлено в этой версии

- Мини-CRM в `/admin/leads`.
- Расширенные статусы заявок: новая, в работе, замер, смета, завершено, отказ.
- Поиск по имени, телефону, услуге и адресу.
- Фильтр по статусам и счётчики.
- Карточка заявки с адресом, бюджетом, комментарием клиента, заметкой менеджера и датой следующего контакта.
- Экспорт заявок в CSV.
- Удаление заявки.
- Публичная форма теперь передаёт адрес участка и примерный бюджет/масштаб.

## Первый запуск

### server

```bash
cd server
yarn install
cp .env.example .env # если используешь свой env-шаблон
npx sequelize-cli db:migrate
npx sequelize-cli db:seed:all
pm2 start app.js --name cedarforma-api
```

### client

```bash
cd client
yarn install
yarn build
```

## Админка

Локально:

```text
http://localhost:3000/admin
```

На проде:

```text
https://cedarforma.ru/admin
```

Стартовый доступ из сидера:

```text
login: admin
password: admin12345
```

После первого входа создай нового админа с нормальным паролем и отключи/удали стартового.

## Важно по базе

Если база уже была создана старой версией, а миграции уже применены, проще для старта на чистом проекте пересоздать базу и прогнать миграции заново. Если данные уже боевые, надо делать отдельную миграцию `add-fields-to-leads`, а не пересоздавать таблицу.
