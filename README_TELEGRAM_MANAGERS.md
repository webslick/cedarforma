# Telegram-уведомления нескольким менеджерам

Теперь бот умеет сам запоминать менеджеров.

## 1. Создать бота
Создай бота через @BotFather и возьми токен.

## 2. Настроить server/.env
Добавь:

```env
TELEGRAM_BOT_TOKEN=токен_бота
TELEGRAM_JOIN_PASSWORD=пароль_для_подключения_менеджеров
```

`TELEGRAM_CHAT_ID` можно оставить пустым.
Если хочешь вручную добавить получателей, можно указать несколько chat_id через запятую:

```env
TELEGRAM_CHAT_ID=123456789,987654321
```

## 3. Запустить проект

```bash
yarn dev
```

После запуска в консоли сервера должно быть:

```text
Telegram bot polling started
```

## 4. Подключить менеджеров
Каждый менеджер открывает твоего Telegram-бота и пишет:

```text
/start
```

Потом:

```text
/join ТВОЙ_ПАРОЛЬ
```

Например:

```text
/join cedar2026
```

После этого бот ответит:

```text
✅ Готово. Теперь сюда будут приходить новые заявки CedarForma.
```

## 5. Где хранятся менеджеры
Менеджеры сохраняются в MySQL в таблицу:

```text
CedarTelegramSubscribers
```

## 6. Отключение уведомлений
Менеджер может написать боту:

```text
/stop
```

После этого заявки ему приходить не будут.
