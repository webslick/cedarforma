# CedarForma v14: понятные Telegram-статусы

Что изменено:

1. После нажатия статусной кнопки бот редактирует исходное сообщение через `editMessageText`, а не присылает новую копию заявки.
2. В карточке заявки явно видно текущий статус и последнее действие менеджера.
3. Кнопки теперь динамические:
   - `new`: В работу / Замер / Смета / Закрыть / Отказ
   - `in_work`: Замер / Смета / Закрыть / Отказ
   - `measurement`: Смета / Закрыть / Отказ
   - `estimate`: Закрыть / Отказ
   - `done` или `cancelled`: остаются только Телефон и WhatsApp
4. Исправление Telegram `tel:` сохранено: кнопка телефона работает через `callback_data=lead_phone:<id>`, а WhatsApp остаётся через `https://wa.me/...` с очисткой номера.

После обновления:

```bash
cd server
npx sequelize-cli db:migrate
cd ..
yarn dev
```

Проверь новой заявкой и нажатием статусов в Telegram.
